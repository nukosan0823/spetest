# デザインシステム

## 1. 優先順位

次の順でデザインを決める。

1. ユーザーが指定したブランド規定
2. 提供されたPPTXのテーマ、マスター、既存レイアウト
3. 同じ資料内で確立された視覚規則
4. `assets/design-tokens.json` の初期値

初期値を会社テンプレートへ機械的に上書きしない。既存資料では「同じ会社の同じ資料に見えること」を優先する。

## 2. 画面とセーフエリア

- 新規資料は原則16:9。
- 外周に最低5.5%程度のセーフエリアを取る。
- タイトル、本文、図表の左端を共通の基準線へ合わせる。
- フッター領域は本文と分離し、ページ番号、機密区分、出典以外を置かない。
- 投影設備で端が欠ける可能性を考慮し、重要情報を外周へ寄せない。

既存テンプレートが異なる比率や余白を持つ場合は、既存値を使う。

## 3. グリッド

新規16:9資料は、左右の余白を含む12列グリッドを基準にする。

- 列間の間隔は一定にする。
- テキストと図表の端を列境界へ合わせる。
- 一つのページで基準線を増やしすぎない。
- 視覚上の中央と数値上の中央が違う場合は、視覚上の均衡を優先する。
- 近接した要素は同じグループ、離れた要素は別グループとして見える間隔を取る。

整列の優先順位:

1. 左端
2. 上端
3. ベースライン
4. 中央
5. 右端

中央揃えは表紙、区切り、単一メッセージなど限定した構成に使う。

## 4. 余白と間隔

余白を「空き」ではなく、情報の階層を示す要素として使う。

- タイトルと本文の間隔は、本文内の行間より大きくする。
- セクション間の間隔は、同一セクション内の間隔の1.5〜2倍にする。
- 図表と解説の関係を近接で示す。
- 同じ種類のページでは、同じ余白規則を使う。
- 埋める目的で図形、アイコン、注釈を追加しない。

## 5. 日本語タイポグラフィ

### フォント

- 会社指定フォントを最優先する。
- 指定がなければ、環境に存在する可読性の高い日本語サンセリフを使う。
- 例: Yu Gothic、Noto Sans JP、Meiryo。
- 一つの資料で本文フォントを混在させない。
- 英数字も日本語フォントと調和する字形を選ぶ。

### 文字サイズの初期値

投影用16:9資料の目安:

| 用途 | 目安 |
|---|---:|
| 表紙タイトル | 32〜44pt |
| ページタイトル | 24〜30pt |
| リード文 | 18〜22pt |
| 本文 | 16〜20pt |
| 図表ラベル | 14〜18pt |
| 注記・出典 | 10〜12pt |

既存テンプレートでは既存値を優先する。ただし投影時に読めない場合は、情報量を減らしてサイズを確保する。

### 組版

- 本文の行間は文字サイズの1.25〜1.45倍を目安にする。
- 箇条書きの段落間は、行間よりわずかに広くする。
- 一行を長くしすぎない。本文欄では25〜35字程度を目安にする。
- 助詞だけが行頭へ残る改行を避ける。
- 句読点、閉じ括弧、長音を行頭へ置かない。
- 開き括弧を行末へ残さない。
- 単位と数値、製品名、固有名詞を不自然に分断しない。
- 英数字の全角・半角を資料内で統一する。
- 強調のために太字、色、下線を同時に使わない。

## 6. 情報階層

視覚階層は最大4段階にする。

1. アクションタイトル
2. 主要メッセージまたは主要数値
3. 根拠となる本文・図表
4. 注記・出典

大きさ、太さ、色、位置のうち二つ以内で差をつける。すべての差を同時に使うと騒がしくなる。

## 7. 色

色の役割を固定する。

- **ベース色**: タイトル、軸、主要な線
- **アクセント色**: 今見てほしい系列、推奨案、変化点
- **補助色**: 比較対象、過去、背景情報
- **警告色**: リスク、遅延、異常。常用しない
- **背景色**: 原則白または低彩度の明色

一枚で強いアクセント色は原則一つ。重要でない要素を無彩色へ下げ、重要要素だけを色で上げる。

色だけに意味を持たせない。ラベル、記号、線種、位置も併用する。赤と緑だけの対比を避ける。

`assets/design-tokens.json` はブランド指定がない場合の中立的な初期値であり、会社のブランド色を模倣するものではない。

## 8. コントラスト

- 本文は背景との明度差を十分に取る。
- 淡色の文字を白背景へ置かない。
- 写真上の文字は、写真の明暗に依存しない帯または十分なオーバーレイを使う。
- プロジェクターで薄くなることを想定し、細い淡色線だけで区切らない。
- グレーは階層を下げるために使い、主要本文を薄くしない。

## 9. 線、枠、面

- 枠線は境界が必要な箇所だけに使う。
- 影は原則使わない。使う場合も一種類に限定する。
- 角丸の小箱を全面へ敷き詰めない。
- セクション分けは余白、整列、背景面のいずれか一つで示す。
- 区切り線は細く、低彩度にする。
- 図形の線幅と矢印の形を統一する。

## 10. デッキ全体のリズム

- 表紙と区切りは情報量を減らす。
- 要約の後に根拠、根拠の後に判断を置く。
- 密度の高いページを連続させない。
- 同じレイアウトを使う連続ページでは、比較可能性を保つ。
- 変化をつけるためだけに背景色やタイトル位置を変えない。
- ページ番号、タイトル領域、フッター位置を安定させる。

## 11. アクセシビリティ

- 読み上げ順をタイトル、主要メッセージ、本文、注記の順にする。
- 画像には代替テキストを付けられる場合は付ける。
- 色覚だけに依存しない。
- 小さい文字や細い線に重要情報を置かない。
- 動画、アニメーション、画面切替に意味を依存させない。

## 12. 避ける表現

- 意味のない巨大な引用符
- 写真の上へ長文を直接配置
- 多数の小カードを均等配置したダッシュボード風ページ
- 装飾用の円、波線、点線、グラデーションの反復
- 3種類を超えるフォントウェイト
- すべてを中央揃え
- 低コントラストのライトグレー本文
- 文章を小さくして一枚へ押し込む
- ページごとに変わる色の意味
