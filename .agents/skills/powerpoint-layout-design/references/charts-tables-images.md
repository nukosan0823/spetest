# チャート、表、画像、図解

## 1. 表現を選ぶ

| 伝えたいこと | 第一候補 |
|---|---|
| 項目間の大小 | 横棒グラフ |
| 時間による変化 | 折れ線グラフ |
| 全体に占める構成 | 100%積み上げ棒 |
| 二変数の関係 | 散布図 |
| 正確な値と条件 | 表 |
| 手順や依存関係 | プロセス図 |
| 二軸の分類 | 2×2マトリクス |
| 人、場所、製品の具体像 | 写真または図 |

円グラフは項目が少なく差が大きい場合だけ使う。3Dチャートは使わない。

## 2. チャートの設計

### 結論から作る

チャートを作る前に、読み手に見つけてほしい事実を一文で書く。その一文をページタイトルにし、チャートが直接支えるか確認する。

### 比較を正しくする

- 棒グラフの数値軸は原則0から始める。
- 折れ線は変化を読みやすくする範囲を使い、軸を省略・切断するときは明示する。
- 時間は左から右へ進める。
- カテゴリは、自然順、数値順、業務上の順のいずれかへ統一する。
- 異なる単位を一つの軸へ混ぜない。
- 二軸グラフは誤解を生みやすいため、分割または指数化を優先する。

### 色と強調

- 注目系列をアクセント色にする。
- 比較対象と過去値はグレーまたは低彩度にする。
- 同じ系列は資料全体で同じ色にする。
- 色だけで識別せず、直接ラベルまたは線種を併用する。
- 警告色を通常系列へ使わない。

### ラベル

- タイトル、単位、期間、母数を示す。
- 直接ラベルを優先し、凡例と視線を往復させない。
- データラベルは結論に必要な値へ限定する。
- 小数桁、通貨、桁区切り、パーセント表記を統一する。
- 注釈は転換点、外れ値、施策開始など2個程度までにする。

### ノイズを減らす

- 目盛線を必要最小限にする。
- 枠、背景、影、立体効果を外す。
- すべての点へマーカーを付けない。
- 系列数が多い場合は、スモールマルチプルまたはページ分割を検討する。

## 3. 表の設計

表は「値を正確に参照する」用途に使う。傾向を見せるだけならチャートを選ぶ。

- 行と列を判断に必要なものへ限定する。
- 見出しを短くし、単位を見出しへ含める。
- 数値は右揃え、小数点位置と桁数を揃える。
- テキストは左揃えを基本にする。
- 行の高さとセル内余白を確保する。
- 罫線は横方向を中心に最小限とする。
- 縞模様は行追跡に必要な長い表だけに使う。
- 強調は1〜2行または列へ限定する。
- 合計、平均との差、目標との差を必要に応じて明示する。

本編で6行×5列を超える場合は、要点だけを本編へ出し、詳細を付録へ移す。

## 4. 画像

### 使う条件

次のいずれかを満たす画像だけを使う。

- 読み手が対象物を認識するために必要
- 説明文より早く状況を理解できる
- 空間、人物、製品、操作を具体的に示す
- 感情的な文脈が資料の目的に必要

### 配置

- 画像の縦横比を維持する。
- 主役が余白やタイトルと競合しないようにトリミングする。
- 小さい画像を引き伸ばさない。
- 同じページで複数画像を使う場合は、寸法とトリミング規則を揃える。
- 文字を写真へ直接置く場合は、可読性を保証する面またはオーバーレイを使う。
- 画像に枠と影を同時に付けない。

### 出典

外部画像には出典とライセンスを記録する。生成画像は生成物であることを社内規定に応じて示す。人物や機密情報が含まれる画像は利用許可と共有範囲を確認する。

## 5. アイコン

- ラベルだけで十分な場合は使わない。
- 同一資料では線、塗り、太さ、視点を統一する。
- 一つの意味へ一つのアイコンを対応させる。
- 装飾目的で各箇条書きへ異なるアイコンを付けない。
- 企業ロゴや製品ロゴを一般概念のアイコンとして使わない。

## 6. 図解

図解は関係を示す。図形の数ではなく、関係の種類を先に決める。

| 関係 | 表現 |
|---|---|
| 順序 | 一方向の矢印と番号 |
| 階層 | 上下配置と包含 |
| 入出力 | 左から右の流れ |
| 循環 | 本当に開始点がない場合だけ円環 |
| 分岐 | 条件ラベル付きの分岐 |
| 所有 | スイムレーンまたは担当ラベル |

### コネクター

- 矢印は必ず図形の接続点へつなぐ。
- 線を図形の下へ通さない。
- 交差を避ける。
- 同じ種類の関係は同じ線種と矢印にする。
- 分岐条件を線の近くへ置く。
- 逆方向の矢印を混在させない。

## 7. スクリーンショット

- ブラウザやアプリの不要なUIを切り取る。
- 注目箇所を一つに絞り、番号または短い注釈を付ける。
- 個人情報、トークン、URL、通知を確認する。
- 文字が読めない全画面キャプチャを避け、必要部分を拡大する。
- 注釈図形は元画像と別の編集可能要素にする。

## 8. 検査

- チャートがタイトルの主張を支えている。
- 単位、期間、母数、出典がある。
- 数値が入力データと一致する。
- 色の意味が資料全体で一貫している。
- 表の列幅、数値揃え、折返しが読みやすい。
- 画像が低解像度または不自然なトリミングでない。
- 図解の矢印が交差せず、関係が一意に読める。
